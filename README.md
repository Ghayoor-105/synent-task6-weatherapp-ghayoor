# Weather App 🌤️

A real-time weather web application built with Flask and OpenWeatherMap API.

## Features
- Search weather for any city worldwide
- Shows temperature, humidity, wind speed, pressure, visibility
- Sunrise and sunset times
- Beautiful dark UI
- Quick city shortcuts

## Tech Stack
- Python, Flask
- OpenWeatherMap API
- HTML, CSS

## How to Run
pip install -r requirements.txt
python app.py

Open browser at http://127.0.0.1:5000
